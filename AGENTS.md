# AGENTS

## Requests

- Send shell/tool commands **one at a time** — no batches, no parallel tool calls.
- Commit style: **concise, English, with a `[tag]` prefix** (e.g. `[backup] add ...`). No Co-Authored-By.
- After a change, **always commit and push** — don't ask, just do it.
- Before running the actual `git commit`, **always show the changes** (`git status` / `git diff --cached`) so you know exactly what you are committing.
